# SPEC NOTES — M3 shape scale (corner radius tokens)

Written for task A2 (ShapeTokens lookup + naming fix) before coding, per the multi-agent
protocol.

## Sources

- Material design tokens, generated SASS vars for **Material 3 v34.0.21** (the token set the
  library's other spec notes cite as "v34"):
  https://raw.githubusercontent.com/material-components/material-web/main/tokens/versions/latest/sass/_md-sys-shape.scss
  (autogenerated, fetched 2026-11-20). Every corner value below is quoted from that file's
  `md.sys.shape.corner-value.*` entries.
- m3.material.io — "Shape overview" (https://m3.material.io/styles/shape/overview) for the
  conceptual model (shape scale = the corner radii system components use). JS-rendered; only
  headings extractable on 2026-11-20, so it is cited for the concept, not values.

## The scale (spec names → corner radius)

| `md.sys.shape.corner.*` | dp | Notes |
|---|---|---|
| `none` | 0 | sharp corners |
| `extra-small` | 4 | |
| `small` | 8 | |
| `medium` | 12 | |
| `large` | 16 | |
| `large-increased` | 20 | Expressive addition (v34) |
| `extra-large` | 28 | |
| `extra-large-increased` | 32 | Expressive addition (v34) |
| `extra-extra-large` | 48 | Expressive addition (v34) |
| `full` | 9999 | pill/circle sentinel ("Use for: Badge, Buttons, Icon buttons, Sliders, Switches, Search bar") |

The v34 file contains exactly these ten scalar corner values (plus directional composites like
`corner.large.top`, which are not part of the scalar scale). `full` is `9999px` in the tokens —
not "a very large number"; JavaFX clamps oversized arc radii proportionally, so it behaves as a
pill/circle sentinel (already documented on the `FULL` constant).

## A2 naming decisions

- The pre-A2 constants `EXPRESSIVE_LARGE_INCREASED` (32) and `EXPRESSIVE_EXTRA_EXTRA_LARGE`
  (48) used the wrong prefix: the spec names are `extra-large-increased` and
  `extra-extra-large`. Renamed to `EXTRA_LARGE_INCREASED` / `EXTRA_EXTRA_LARGE`; the old
  constants remain as `@Deprecated` aliases pointing at the new ones (no external callers
  existed — verified by grep before the rename).
- `forName()` gains the three missing lookups: `none` (0), `extra-large-increased` (32) and
  `extra-extra-large` (48). Unknown *or null* names return the documented default `none` (0),
  mirroring `TypeScale.forName`'s unknown-name default.
